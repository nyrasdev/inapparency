# Code of conduct

Be kind and assume good intent. Beginners are welcome here, and nobody
should feel stupid for asking a question.

Not okay: harassment, insults, personal attacks, discrimination of any kind,
or posting other people's private information. That includes MAC addresses,
network names or captures from networks that aren't yours.

Disagreeing about code is fine. Keep it about the code.

If someone makes you uncomfortable, email **fer@nyras.dev**. Reports are kept
private. People who don't follow this can be warned, have comments removed,
or be blocked from the project.
